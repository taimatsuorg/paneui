# Docs and template showcase

Static documentation site, live component studio, Markdown documentation generator, and downloadable application templates.

## Layout

| Path | Role |
| --- | --- |
| `src/pages/` | File-based routes, raw skill downloads (`src/pages/skills/`), and redirects |
| `components/pages/` | Client-hydrated page views mounted as React islands |
| `components/docs/` | Navigation, two-panel component studio, theme sync, gallery, and search |
| `components/landing/` | Landing page showcase sections |
| `content/docs/` | Per-item docs data (`summary`, `usage`, `composition`, `examples`, `notes`, `api`) and generated index (`index.generated.ts`) |
| `registry/examples/` | Consumer-linted per-item demos (`<name>-demo.tsx`) and named example snippets (`<name>/<id>.tsx`) |
| `registry/templates/` | Full-screen templates (`saas`, `vscode`, `agent-workspace`, `docs`, `blog`, `team-chat`) |
| `public/r/` | Built registry JSON files (`registry.json`, `<name>.json`) and `llms.txt` generated by `pnpm registry:build` |
| `out/` | Static HTML, browser assets, `/docs/*.md`, and combined `/native/` output |

## Architecture notes

- **Library-built shell**: site chrome composes `@paneui/ui` components directly (`NavigationMenuLink` tabs in `site-shell.tsx`, `SidebarNav` in `docs-nav.tsx`, `Outline` / `OutlinePopover` in `doc-toc.tsx`, `PageHeader`, interactive `Card` tiles, and `SimpleTable`).
- **Component studio**: component pages split into a stage panel (live preview vs Code view) and a sticky rail with variant/example selectors and viewport size switches. Legacy hash anchors (`#variant-*`, `#example-*`, `#api-*`, `#note-*`) resolve directly to the selected state.
- **Preview theme sync**: `theme-sync.tsx` mirrors `dark`, `data-accent`, custom accent CSS, `data-style`, and `--radius` from `<html>` into preview and template iframes and across open tabs.

## Authoring component docs

1. Add consumer-clean demos at `registry/examples/<name>-demo.tsx` and named examples under `registry/examples/<name>/<id>.tsx`.
2. Add the page definition at `content/docs/<name>.ts` (matching `ComponentDoc` in `lib/doc-types.ts`; document only props added or changed by PaneUI).
3. Register the main demo in `components/docs/demos.tsx`.
4. Run `pnpm docs:gen` to regenerate `content/docs/index.generated.ts` and `components/docs/examples.generated.tsx`, and commit both.
5. After editing template code samples in `tooling/scripts/gen-template-code.mjs`, run `pnpm templates:code` to update `registry/templates/*/parts/code.ts`.

## Markdown export

`pnpm build` runs the static build followed by `tooling/scripts/gen-docs-md.mjs` to emit Markdown copies under `out/docs/*.md`. Guide pages are converted from HTML using markup hooks (`data-md-skip`, `data-md-text`, `data-md-only`, `data-md-after`, `data-md="links"`). Always verify zero issues with `pnpm docs:md:audit`.

Note that `pnpm --filter @paneui/docs typecheck` reports 19 pre-existing `TS2307` errors on `next`/`next/og` template routes under `registry/templates/{next-og,saas}`; all docs shell and component files are expected to have zero TypeScript errors.
