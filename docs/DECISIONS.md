# Decisions

Settled architecture and governance choices for PaneUI, why each exists, and what it forbids. Append-only — never edit or delete an old row; to supersede one, add a new row and note what it replaces. If a task needs to reverse a decision, stop and ask the owner.

| # | Decision | Why | Forbids | Owner | Date |
| --- | --- | --- | --- | --- | --- |
| `D-001` | Store first-party design, icon, and copy skills in `.agents/skills/{paneui-design,paneui-icons,copy-density}` (with matching `.claude/skills` symlinks) and remove redundant third-party design skills | Keeps one canonical rule set and static checker without conflicting external style rules | Re-adding competing external UI/design skills or maintaining a separate copy of the rules outside `.agents/skills/` | Wang Qinyang | 2026-11-24 |
| `D-002` | Generate theme CSS (`globals.css`, `theme-paper.css`, `theme-studio.css`, `theme-accents.css`) and portable Native colours (`colors.generated.ts`) via `pnpm tokens:gen`, gated by `pnpm tokens:contrast` | Keeps light/dark modes, accents, Paper/Studio styles, Web, Native, and OG cards aligned and contrast-verified (4.5:1 text, 3:1 controls) | Editing generated CSS token blocks or `colors.generated.ts` by hand, or adding colour tokens without contrast verification | Wang Qinyang | 2026-10-30 |
| `D-003` | Default theme uses neutral OKLCH surfaces with translucent hairlines, a `16px` (`--radius-max: 1rem`) radius cap, and `frame-*` / `rounded-inner` concentric nesting | Prevents raw colour drift, pill-distortion of containers above `16px`, and mismatched nested corners across presets | Raw Tailwind palette/hex colours in UI code, `rounded-4xl`/`5xl` or radii > 1rem, restyling library components in consumers, or nesting radii without `frame-*`/`rounded-inner` | Wang Qinyang | 2026-11-24 |
| `D-004` | Keep third-party provenance and reference project names strictly in `THIRD_PARTY_NOTICES.md` | Avoids leaking provenance phrasing or unlisted product/library names into code comments, UI copy, demo data, or public docs | Provenance phrases (`inspired by`, `port of`, `based on`) or blocklisted third-party names outside `THIRD_PARTY_NOTICES.md` (enforced by `design:check` `forbidden-names`) | Wang Qinyang | 2026-10-16 |
| `D-005` | Treat workspace packages (`packages/ui`, `packages/core`, `packages/tokens`, `.agents/skills/paneui-design`) as the single registry source, rewritten into portable output by `pnpm registry:build` | Prevents duplicated implementations drifting from published JSON items and strips internal `@paneui/*` imports and repo lint suppressions | Maintaining duplicate component files in `packages/registry/` or publishing unresolved `@paneui/*` workspace specifiers | Wang Qinyang | 2026-10-29 |
| `D-006` | Keep Web docs (`/`) and Native showcase (`/native/`) as independent bundles merged into `apps/docs/out/` by `pnpm build:cloudflare`, with `packages/core` free of platform APIs | Preserves static route resolution and 404 semantics for both apps without cross-renderer bundler leaks | Adding a global SPA rewrite fallback or importing DOM/Browser/React Native APIs into `packages/core` | Wang Qinyang | 2026-10-29 |
| `D-007` | Build docs chrome from `@paneui/ui` components with two-panel studio component pages and emit audited Markdown twins (`pnpm build && pnpm docs:md:audit`) | Makes the docs site the first consumer of library components and keeps LLM/Markdown exports clean | Writing custom shell widgets where a library component fits, or leaving findings in `pnpm docs:md:audit` | Wang Qinyang | 2026-11-03 |
| `D-008` | Render external product logos through `BrandIcon` using named imports from `@ridemountainpig/svgl-react` (and `{ light, dark }` pairs where needed) | Replaces vendored brand path files and `simple-icons` cleanly with minimal tree-shakeable SVG imports | Namespace imports (`import * from "@ridemountainpig/svgl-react"`), hand-drawn third-party brand SVGs, or re-adding `simple-icons`/`brand-marks.ts` | Wang Qinyang | 2026-11-24 |
| `D-009` | Maintain paired rounded and emoji hand-drawn house icon sets with matching exports, and place title/card icons inside `IconChip` | Keeps navigation, controls, and cards visually coherent across both icon styles | Adding a house icon to only one style file or rendering bare title/card icons without `IconChip` | Wang Qinyang | 2026-10-28 |
| `D-010` | Target PRs to `dev`, merge to `main` only from `dev` or `hotfix/*`, enforce scoped Conventional Commits in CI, and release `@taimatsu/paneui` only via `cli-v*` tags (OIDC) | Prevents unreviewed pushes to the deployed Cloudflare Pages branch and keeps npm releases reproducible without stored tokens | Direct commits/pushes to `main`, scopeless commit subjects, or manual local `npm publish` | Wang Qinyang | 2026-10-29 |

## How to add one

1. Record decisions that change architecture, workflow, or contributor boundaries (not one-off implementation details).
2. Name the owner and exact date (`YYYY-MM-DD`).
3. State what the decision forbids so reviewers can enforce it mechanically.
4. Add a matching check row in [`REVIEW.md`](REVIEW.md) citing `D-###`.
